MLCs are the lead components that shape the fields create the fields within radiotherapy, though only used for MV [[On Particle Interactions#Photons|Photon]]s, with [[On Particle Interactions#Electrons|Electrons]] and superficial photons using applicators; whereas [[Proton Therapy|Protons]] function like a CRT television.  Some key aspects to consider are that they have tongues and grooves in order to minimise the [[On Particle Interactions#Cross-section|Attenuation]] between leaves, as well as rounded tips to minimise changes in the variation of the penumbra.

Old versions of eclipse would find a "dosimetric leaf gap" by extrapolating the data collected for smaller and smaller fields to a point where there would (hypotheticall) have 0 output.  Newer versions of eclipse continue to do this but also have far more advanced structures for the MLCs.

The [[Beam Data-UN 14-10-2026-2#Profiles|Penumbra]] around the edges of these fields will vary both due to the geometric and the transmission variations across the edges of the MLCs.  With beam models utilising two points of emission, one which represents the primary high-energy photons, and a second that represents the scatter from the head of the gantry.
